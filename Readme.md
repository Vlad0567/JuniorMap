# JuniorMap

JuniorMap - это веб-приложение, созданное для помощи начинающим программистам в освоении навыков и технологий, необходимых для успешного трудоустройства на позицию Junior-разработчика.

---

## Основной функционал

**Граф визуальной дорожной карты**  
   - Интерактивное отображение учебных модулей с последовательностью их изучения.  
   - Возможность перехода к обучающим материалам прямо с графа.  

**Регистрация и авторизация**  
   - Возможность создания аккаунта и входа в систему.  
   - Прогресс сохраняется для каждого пользователя. 

**Обучающие секции**  
   - Разделение на тематические блоки: Frontend, Backend, базы данных, DevOps и др.  
   - Поддержка текстового контента и тестирования.  
   - Визуализация прогресса по каждому разделу. 

**Тестирование знаний**  
   - Вопросы с мгновенной проверкой правильности ответов.  
   - Итоговый результат отображается дробно и в процентах.  
   - Возможность повторного прохождения теста.

**Профиль пользователя**  
   - Отображение имени пользователя.  
   - Общий прогресс в процентах и числовом значении.  
   - Детальный прогресс по каждой секции.

## Демонстрация работы 

### Визуальная дорожная карта  
На графе представлены ключевые темы и их взаимосвязи, обеспечивая понятную структуру обучения.  
![Граф обучения](https://github.com/user-attachments/assets/b1219a42-2487-4811-ae1a-5287c29a4a66)  

### Регистрация и авторизация  
Создание аккаунта и вход в систему для сохранения прогресса.  
![Регистрация и вход](https://github.com/user-attachments/assets/9fedfe72-1ae3-42d8-86d0-9af414fb8fbb)  

### Профиль пользователя  
В профиле отображается никнейм, общий прогресс (в процентах и числовом значении), а также индивидуальный прогресс по каждой секции.  
<img width="619" alt="Image" src="https://github.com/user-attachments/assets/3c3ba828-6893-48d0-9ce9-2089e57f1508" />

### Всплывающее меню секций  
При нажатии на тему открывается список обучающих материалов, а у уже пройденных секций индикатор нового урока отсутствует.  
<img width="346" alt="Image" src="https://github.com/user-attachments/assets/2cec2b2f-94bf-4813-b01f-35369ef34526" />

### Тестирование знаний  
Интерфейс тестов позволяет сразу видеть результат ответа (правильный/неправильный). В конце теста отображается итоговый результат и возможность пройти его заново.  
![Прохождение теста](https://github.com/user-attachments/assets/2bca2459-70be-49f3-b993-c5634f25f870)  

### Изменение статуса секций на графе
При прохождении всех тем в секции её цвет изменяется, обозначая завершение. Начатые, но не завершенные секции также имеют свой цветовой статус, отличающий их от непройденных.
